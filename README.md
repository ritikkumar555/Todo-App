# ✅ Todo App

A simple and interactive Todo application built with **HTML, CSS, and JavaScript** to practice DOM manipulation and core frontend development concepts.

## 🚀 Live Demo

**[View Live Demo](https://ritikkumar555.github.io/Todo-App/)**

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 📋 Manage daily tasks through an interactive interface

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript (Vanilla JS)** — Application logic and interactivity

## 📚 Concepts Practiced

- DOM manipulation
- Event handling and event listeners
- JavaScript functions and arrays
- Dynamic UI updates
- Managing user interactions
- CRUD fundamentals

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ritikkumar555/Todo-App.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Todo-App
   ```

3. Open `index.html` in your browser.

No additional dependencies are required.
